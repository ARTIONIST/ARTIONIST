# Benchmark Protocol

A: normal baseline model.
B: multi-model system without the Problem = Solution control protocol.
C: MMI-PSAI X1.

Use held-out cases, fresh sessions, blind scoring, fixed rubrics, repeated runs and independent evaluators.

Metrics: factual accuracy, root-cause accuracy, unsupported-claim rate, evidence discipline, correction-after-challenge, robustness, reproducibility, cost, latency.

Do not call a system "best" from one run.
